## Páginas

- `index.html`: página inicial com estoque, filtros, favoritos, venda de veículo e painel do administrador
- `login.html`: login e cadastro de usuários
- `agendar.html`: agendamento de test drive (somente para usuários logados)
- `curriculo.html`: página "Trabalhe conosco" para envio de currículo
- `style.css`: estilos compartilhados

## Como abrir

Abra o `index.html` no navegador ou acesse a versão publicada pelo GitHub Pages.

Os dados (usuários, agendamentos, currículos e favoritos) ficam salvos no `localStorage` do navegador.
